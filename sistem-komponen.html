💻 Sistem Komputer & Komponennya

🎯 Tujuan Pembelajaran

Setelah mempelajari materi ini, siswa mampu:

  • Menjelaskan pengertian sistem komputer.
  • Mengidentifikasi dan mendeskripsikan komponen-komponen utama komputer (hardware, software, brainware).
  • Menjelaskan fungsi masing-masing komponen komputer.
  • Menggambarkan cara kerja komputer secara sederhana (proses input – proses – output).

A. APA ITU SISTEM KOMPUTER?

Sistem komputer adalah kumpulan dari perangkat keras (hardware), perangkat lunak (software), dan pengguna (brainware) yang saling terhubung dan bekerja sama untuk mengolah data menjadi informasi yang berguna.

🍽️ Analogi: Restoran

  • Hardware (perangkat keras) = peralatan dapur (kompor, wajan, pisau).
  • Software (perangkat lunak) = resep masakan.
  • Brainware (pengguna) = koki yang memasak.

Tanpa salah satu dari ketiganya, restoran tidak bisa menghasilkan masakan yang enak. Begitu pula komputer tidak akan berguna tanpa salah satu komponen tersebut.

B. KOMPONEN SISTEM KOMPUTER

Sistem komputer terdiri dari 3 elemen utama:

1. Hardware (Perangkat Keras)

Adalah semua bagian fisik dari komputer yang bisa kita lihat, raba, dan sentuh.

Berdasarkan fungsinya, hardware dibagi menjadi 4 kelompok:

Kelompok Fungsi Contoh
a. Perangkat Input Alat untuk memasukkan data ke dalam komputer. ⌨️ Keyboard, 🖱️ Mouse, 🎤 Mikrofon, 📷 Webcam, Scanner, Touchscreen.
b. Perangkat Proses Otak komputer yang mengolah data. 🧠 Processor (CPU) – tempat semua perhitungan dan logika terjadi.
c. Perangkat Output Alat untuk menampilkan hasil olahan data. 🖥️ Monitor, 🖨️ Printer, 🔊 Speaker, 📽️ Proyektor.
d. Perangkat Penyimpanan Alat untuk menyimpan data dan program. 💾 Hard Disk (HDD), SSD, RAM (penyimpanan sementara), Flashdisk, CD/DVD.

💡 Perhatikan: RAM (Random Access Memory) itu unik. Ia menyimpan data sementara selama komputer menyala. Jika mati, data di RAM hilang. Sedangkan HDD/SSD menyimpan data secara permanen meskipun komputer mati.

2. Software (Perangkat Lunak)

Adalah kumpulan instruksi atau program yang mengatur hardware agar bisa melakukan tugas tertentu. Software tidak bisa dipegang, tapi bisa diinstal dan dijalankan.

Software dibagi menjadi 3 jenis:

Jenis Fungsi Contoh
a. Sistem Operasi (OS) Menghubungkan user dengan hardware. Mengelola semua sumber daya komputer. 🪟 Windows, 🍎 macOS, 🐧 Linux, 📱 Android, 📱 iOS.
b. Program Aplikasi Program yang digunakan untuk menyelesaikan tugas spesifik pengguna. 📝 Microsoft Word, 🌐 Chrome, 🎨 Photoshop, 🎮 Game.
c. Bahasa Pemrograman Digunakan untuk membuat program/aplikasi. 🐍 Python, ☕ Java, C++, 🧩 Scratch.

3. Brainware (Pengguna/Manusia)

Adalah orang yang mengoperasikan dan memanfaatkan komputer. Tanpa brainware, komputer hanyalah benda mati.

Brainware dibagi berdasarkan perannya:

  • 👨‍💻 Programmer: Orang yang membuat software.
  • 🛠️ Administrator: Orang yang mengelola jaringan dan sistem.
  • 👤 Operator/User: Orang yang menggunakan komputer untuk bekerja atau belajar (kalian termasuk ini!).
  • 📊 Analis: Orang yang merancang sistem untuk perusahaan.

C. FUNGSI UTAMA KOMPUTER

Secara garis besar, komputer memiliki 4 fungsi utama:

  1. 📥 Menerima Input (Data) → dari pengguna melalui perangkat input.
  2. ⚙️ Memproses Data → mengubah, menghitung, membandingkan data di dalam CPU.
  3. 📤 Menghasilkan Output (Informasi) → menampilkan hasil ke perangkat output.
  4. 💾 Menyimpan Data & Informasi → menyimpan untuk digunakan di masa depan.

D. CARA KERJA KOMPUTER (Siklus Pemrosesan Data)

Cara kerja komputer mengikuti alur yang sangat sederhana, yaitu Siklus Input – Proses – Output – Storage. Mari kita lihat langkah demi langkah:

📥 1. INPUT

Pengguna mengetik huruf "A" di keyboard.
→ Data ini berupa sinyal listrik dikirim ke CPU.

⚙️ 2. PROSES (DI DALAM CPU)

Di dalam CPU ada 3 bagian penting:

  • 🔢 ALU (Arithmetic Logic Unit): Bertugas menghitung (+, -, ×, ÷) dan membandingkan (lebih besar, sama dengan).
  • 🎛️ CU (Control Unit): Bertugas mengatur lalu lintas data, mengartikan instruksi dari software, dan memberi perintah ke komponen lain.
  • 📋 Register: Tempat penyimpanan data kecil dan super cepat di dalam CPU.

Prosesnya:

  1. CU membaca instruksi dari program (misal: "tampilkan huruf A di layar").
  2. Data "A" dikirim ke ALU (jika perlu diolah) atau langsung ke CU.
  3. CU kemudian mengirimkan perintah ke kartu grafis (VGA) untuk menampilkan huruf A.

📤 3. OUTPUT

Kartu grafis mengirimkan sinyal ke monitor.
→ Monitor menampilkan huruf "A" di layar. Kita bisa melihatnya.

💾 4. STORAGE (Penyimpanan)

Jika kita menekan tombol Save, maka data huruf "A" tadi akan dipindahkan dari RAM (sementara) ke Hard Disk (permanen) agar tidak hilang saat komputer dimatikan.

📊 Ilustrasi Alur (Bacalah dari kiri ke kanan):

📥 INPUT (Keyboard/Mouse) → ⚙️ PROSES (CPU: ALU + CU) → 📤 OUTPUT (Monitor/Printer)

↕ (Selalu ada RAM sebagai tempat sementara)

💾 STORAGE (Hard Disk/SSD untuk penyimpanan permanen)

E. ANALOGI SEDERHANA (UNTUK DIINGAT)

Bayangkan kamu sedang mengerjakan PR di meja belajar:

Bagian Komputer Analogi di Meja Belajar
🧠 CPU (Prosesor) Otak kamu yang berpikir dan menghitung.
📋 RAM Meja belajar (tempat buku dan alat tulis diletakkan sementara saat mengerjakan PR). Jika PR selesai, meja dibersihkan (RAM kosong).
💾 Hard Disk (HDD/SSD) Rak buku di kamar (tempat menyimpan buku secara permanen, meskipun kamu tidur).
⌨️ Keyboard/Mouse (Input) Tangan dan mata kamu yang membaca soal dan menulis jawaban.
🖥️ Monitor (Output) Buku tulis tempat kamu menuliskan hasil jawaban agar bisa dilihat.

F. RANGKUMAN

  • 💻 Sistem Komputer = Hardware + Software + Brainware.
  • 🖥️ Hardware adalah benda fisik (input, proses, output, storage).
  • 📦 Software adalah program (Sistem Operasi, Aplikasi, Bahasa Pemrograman).
  • 👤 Brainware adalah manusia penggunanya.
  • Cara kerja selalu mengikuti siklus: 📥 Input → ⚙️ Proses → 📤 Output → 💾 Storage.
